Вот что мы ЗАБЫЛИ (23 компонента!):

📦 Базовые:
Kbd — отображение горячих клавиш
Spinner — крутящийся загрузчик
Progress — полоса прогресса
AspectRatio — пропорции контейнера

📝 Формы:
Field — обертка над инпутами (Label + Input + Error)
InputGroup — инпут с иконками внутри
NativeSelect — стилизованный нативный <select>
InputOTP — ввод кода из СМС по ячейкам
RadioGroup — радио-кнопки
Textarea — многострочное поле (отдельной страницей)
Label — подписи к полям (отдельной страницей)

🧭 Навигация:
NavigationMenu — мега-меню в шапке сайта
Menubar — меню как в Photoshop/VS Code
Collapsible — простая сворачивалка
🪟 Оверлеи:
AlertDialog — модалка подтверждения (нельзя закрыть по клику вне зоны)
ContextMenu — меню по правой кнопке мыши
Sonner — всплывающие уведомления (Toasts)

📊 Отображение:
Toggle — кнопка-переключатель (как Bold/Italic)
ToggleGroup — группа переключателей
ButtonGroup — группа кнопок (склеенные)
ScrollArea — кастомный скроллбар
Resizable — изменяемые панели
