🔥 Группа 2: Быстрые победы (Сделаем за 5 минут)
Это компоненты, где почти нет JS, только верстка и стили.

Kbd (отображение клавиш на клавиатуре)
Spinner (крутящийся загрузчик)
Progress (полоса прогресса)
Typography (стили для текста)
Empty (заглушка, когда данных нет)
Collapsible (простая сворачивалка)
Button Group (группа кнопок)
Radio Group (радио-кнопки для форм)
⚡ Группа 3: Оверлеи и Структура
Alert Dialog (модалка подтверждения)
Sheet (выезжающая панель сбоку, как меню на мобильных)
Field (обертка над инпутом с лейблом и ошибкой)
Input Group (инпут с иконкой внутри)
Native Select (стилизованный дефолтный селект)
Hover Card (карточка при наведении)
Context Menu (меню по правому клику мыши)
Toggle / Toggle Group (кнопки-переключатели)
Pagination (постраничная навигация)

План действий:
Давай прямо сейчас снесем Группу 2 (Быстрые победы).
Иди в свой React-проект shadcn-reference и выполни команду:

bash

npx shadcn@latest add kbd spinner progress typography empty collapsible button-group radio-group
(Если какой-то из них не скачается из-за того, что это слишком свежий компонент — не страшно, я напишу его с нуля сам).

Как скачаются — открывай первый файл (например, kbd.tsx или spinner.tsx), копируй код и кидай мне. Мы оформим их за пару минут и пойдем дальше! Погнали, бро!
